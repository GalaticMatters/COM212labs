Why this page exists

A name picked this directory.

Apache is listening on port 80 for every name that arrives on this machine. The default site is still there. This page is served only when the request’s Host header is example.com or www.example.com.

That header is set from the address you typed. Kali learned the address from dnsmasq on Ubuntu, over the veth-peer link. The files themselves are ordinary HTML under /var/www/example.com/public.

If you open the server by its raw IP, you will probably see the Ubuntu default page instead. Same daemon, different virtual host. The name is the switch.
