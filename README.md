# COM212 labs

Read these pages on GitHub and run the commands on the machines. Do not download this repository.

1. [DHCP lab](dhcp-lab.md). Ubuntu gives Kali an address on `veth-peer`.
2. [Web server lab](web-server-lab.md). Start this only after the DHCP lab works. It keeps that network and adds `www.example.com`.
3. [NFS lab](nfs-lab.md). `ubuntu##` is the server and `kali##` is the client. Start this after the DHCP lab. It does not need the web server lab.
